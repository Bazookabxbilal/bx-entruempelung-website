# BX Entrümpelung Website

Dieses Repository enthält die Website für **BX Entrümpelung**.

## Dateien

```text
index.html          Hauptseite der Website
styles.css          Design, Farben, Abstände und Responsive Layout
app.js              WhatsApp-Anfrage, mobiles Menü und Tracking-Hooks
rechtliches.html    Impressum und Datenschutz
robots.txt          Hinweise für Suchmaschinen
sitemap.xml         Seitenübersicht für Suchmaschinen
assets/images/      Ordner für eigene Bilder von Aufträgen
```

## Eigene Bilder ergänzen

Eigene Projektbilder später am besten in `assets/images/` hochladen und dann in `index.html` die Bild-Links austauschen.

Empfohlene Dateinamen:

```text
assets/images/wohnungsentruempelung-frankfurt-1.jpg
assets/images/haushaltsaufloesung-frankfurt-1.jpg
assets/images/keller-entruempelung-frankfurt-1.jpg
assets/images/vorher-nachher-entruempelung-1.jpg
```
