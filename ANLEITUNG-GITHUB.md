# GitHub aufräumen

## Neuer Repo-Name

Empfohlen:

```text
bx-entruempelung-website
```

oder kürzer:

```text
bx-entruempelung
```

## Dateien, die im Repo bleiben sollen

```text
README.md
index.html
styles.css
app.js
rechtliches.html
robots.txt
sitemap.xml
assets/images/README.md
CNAME
```

`CNAME` bitte nur behalten, wenn die bestehende Domain weiter genutzt werden soll.

## Alte verwirrende Dateien löschen

```text
Dok.md
cv.html
projekte.html
kontakt.html
```

Hinweis: `index.html` muss bei GitHub Pages so heißen, weil sie die Startseite ist.

## Upload

1. Alle Dateien aus diesem Paket in das Repository hochladen.
2. Alte Dateien löschen, die nicht mehr benötigt werden.
3. Unter `Settings > Pages` prüfen, ob GitHub Pages weiter auf `main` und `/root` zeigt.
4. Nach 1–3 Minuten die Website testen.
